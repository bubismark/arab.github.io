# בَסْمَة — איך להתקין כאפליקציה במסך הבית

## מה יש כאן (6 קבצים — צריך להעלות את כולם יחד)
- `index.html` — האפליקציה עצמה
- `manifest.json` — הגדרות האפליקציה (שם, אייקון, צבעים)
- `sw.js` — מאפשר עבודה אופליין (בלי אינטרנט)
- `icon-180.png`, `icon-192.png`, `icon-512.png` — האייקונים

חשוב: כל ששת הקבצים חייבים לשבת **באותה תיקייה** כשמעלים.

## שלב 1 — להעלות לאוויר (פעם אחת)
1. בספארי, היכנס ל-**netlify.com/drop**
2. גרור את **כל ששת הקבצים יחד** (או את התיקייה שמכילה אותם) אל החלון
3. תוך שניות תקבל כתובת כמו `https://xxxxx.netlify.app`

## שלב 2 — להוסיף למסך הבית (חייב ספארי, לא אדג'!)
1. פתח את הכתובת שקיבלת **בספארי**
2. לחץ על כפתור השיתוף (ריבוע עם חץ למעלה ⬆️)
3. בחר **"הוסף למסך הבית"** (Add to Home Screen)
4. תן שם ולחץ "הוסף"

זהו! עכשיו יש אייקון אמיתי במסך הבית, שנפתח במסך מלא כמו אפליקציה,
ועובד גם בלי אינטרנט אחרי הפתיחה הראשונה.

## עדכון בעתיד
אם תרצה להוסיף מילים — אעדכן לך את `index.html`, תעלה אותו מחדש לאותו מקום,
ותפתח שוב את האפליקציה כדי שתתעדכן. (אם לא מתעדכן מיד — סגור ופתח שוב).
